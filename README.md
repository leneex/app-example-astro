# Astro

Example [Astro](https://astro.build/) app. Astro is a web framework for content-focused websites that ships pages as HTML with as little JavaScript as possible.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Static site — Railpack build |
| Single-page application (SPA) | off |
| Project directory | `/` |
| Output directory | `/dist` |
| Install command | leave empty |
| Build command | leave empty |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
npm install

# run in dev mode with watch
npm run dev

# build for production with minification
npm run build

# preview the build locally
npm run preview
```

Requires Node.js 22.12 or later.
